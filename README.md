# Ning — GitHub Portfolio

Static GitHub Pages portfolio for **Ning**, an FDE team PM with selected hands-on engineering capability.

**Live site:** [nyannnnning.github.io](https://nyannnnning.github.io)

## Local preview

```bash
npm test
npm run serve
```

Open `http://127.0.0.1:4173`.

## Deployment

Pushes to `main` run the included GitHub Actions workflow, validate the static site, and deploy it to GitHub Pages.

The Open Graph image and metadata are sized for GitHub, LinkedIn, and other social previews.

## Content boundary

The public site intentionally excludes internal URLs, credentials, employee names, private repository links, and customer-sensitive data. It presents delivery practices, outcomes, and sanitized case studies.

The companion GitHub profile lives at [Nyannnnning/Nyannnnning](https://github.com/Nyannnnning/Nyannnnning).
